# Marco Valentino Caga-anan — Social Hub

A responsive, single-page home for Marco’s Facebook, TikTok, and Instagram profiles. The portrait and charcoal / muted teal palette are based on the photo provided for this site.

## Run locally

Requires Node.js 20.19+ (or 22.12+).

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

## Profiles

- Facebook: [marco.valentino.caga.anan](https://facebook.com/marco.valentino.caga.anan)
- TikTok: [@mavrkz0](https://www.tiktok.com/@mavrkz0)
- Instagram: [@mar.codes](https://www.instagram.com/mar.codes)

Update the links and display copy in `src/App.tsx`. Replace `public/marco-profile.jpeg` to change the profile photo.
